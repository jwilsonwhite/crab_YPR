# crab_YPR
Yield per recruit analysis of Dungeness crab with variable molting dynamics because of ocean acidification

The code in this repo performs the analysis associated with this manuscript:
Walker BJ, White JW, Kroeker KJ. From physiology to fishery: calcification stress from ocean acidification is expected to cause only modest growth-mediated declines in fishery yield of Dungeness crab. ICES Journal of Marine Science, submitted

Code written by Will White in Matlab based on original code in R written by Ben Walker.

The .m file is completely self contained and when executed will run the model and create the figures in the manuscript. The single .m file has multiple helper functions embedded within it.
